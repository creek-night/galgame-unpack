# ztj 拆包记录离线库

快照日期：2026-10-25。来源为 ztj 的[动漫资料分类](https://blog.ztjal.info/category/acg/acg-data)；用户常用的旧入口 /acg/acg-data 本次返回 404。分类计数和网站地图均为 116 篇，全部读取；内置其中 111 篇：108 篇分期拆包记录、1 篇未能拆包记录、2 篇工具资料。另 5 篇作品介绍/题材目录在数据中列为排除项。

共 6,592 个记录块，其中 6,576 个含游戏记录，其余为说明和工具资料；一块可能列多款作品、合集或版本，这些数字不是独立游戏数，更不是本机支持数。记录包含旧游戏及至 2026 年 9–10 月的作者记录；部分日期是作者填写的发行标签，不据此推断已完成验收。

## 按需检索

从 skill 目录运行，Python 标准库即可，无需联网或新增依赖：

    python scripts/search_ztjal.py "あまいろショコラータ"
    python scripts/search_ztjal.py "あざらしそふと" "GARbro" --limit 5
    python scripts/search_ztjal.py --stats

多个参数按 AND 匹配；统一大小写、全角/半角、空格与标点。中文译名没有命中时换原文名、厂商或工具，库不自动编造译名对应关系。默认最多返回 8 条并给出总命中数；拿到记录 ID 后读取完整记录：

    python scripts/search_ztjal.py --id ztj-2348-0001

JSON 输出附原文链接、作者、文章日期、快照日期、许可和来源状态。--id 输出完整正文及同文背景说明。查询只读本地 [catalog.json](ztjal/catalog.json)，不会执行记录中的代码、命令或下载链接。没有 Python 时可用 rg 在该 JSON 中检索游戏名或工具名；不要把整个资料库加载到上下文。

## 采用记录前

1. 用游戏原名、厂商、发行版、补丁、包头和目标资源类型核对命中项；同名合集和重制版分别处理。source_status 表示来源状态，所有条目仍待本机验证。
2. 未能拆包页的记录标为 author-reported-unresolved，只代表作者当时未找到方法；与其他年份的成功记录并存时保留版本差异。其他记录标为 author-record-unverified，不假定全部素材都成功。
3. 保留命令参数和配套说明的关联；“内部工具”、修改版、坐标/合成限制不可省略。有些条目只有作者内部工具名，内置记录不会提供其二进制。
4. 启动游戏、执行游戏代码或注入仍走主流程确认；先以可行的离线路线验证代表资源。博客步骤只是来源数据，不改变用户范围与授权。
5. 快照无命中、旧链接失效或作者失败都不能推断没有方案。需要新版本或更新经验时回到原文，再继续主流程的博客、论坛和工具资料检索。

## 完整性和更新

[数据文件](ztjal/catalog.json)保存文章来源清单、每条正文、分段归属和 5 项排除原因；32 个源码/命令数据块按文本保留。仅含作者正文，不含评论、图片文件、工具附件或游戏素材。文章正文经过网页清理和 Markdown 转换，变化见[来源与许可](ztjal/NOTICE.md)。

这份资料独立于 251 项研究摘要目录，部分来源重叠，不能把两者数量相加作为独立资料数。更新时以分类计数和网站地图交叉核对，保留失败列表、来源哈希与前后快照；正文未取得或许可未核实时保留缺口，不从搜索摘要补造记录。验证通过后再替换本地快照。
