# 维护者历史样本验证范围

本页列出具体样本结论，不承诺完整游戏或全部引擎变体。游戏资源、破解程序、私有 profile 与本地日志不随仓库分发；公开版的合成夹具检查另见仓库 tests。

## 2026-10-20 新增离线验收

G14 新一轮独立实提取已恢复开场 `eva01_01` CG：脚本加载器引用 `.dref`，其两条精确引用定位 DPAK 内底图与差分；依据 PNG `oFFs/vpAg` 还原为 1920×1080，独立遮罩替换与 alpha-over 全像素相同。教师立绘及 14 张原层一并验证，共 16 张 PNG。该场景的映射已解决，下面 10-18 的 partial 是保留的历史结果；其他 CG、补丁加载次序与运行时效果仍未全量验证。

新增媒体验证：G08 的真实 OGG BGM、其派生 WAV 对照，以及 G02 独立新提取的 107.5 秒 OGG BGM 完整解码通过；未实际试听。文本使用真实日文说明文件核对 cp932 与 UTF-8；这不代表剧情解析器已经完成。Hxv4 type-1 文本在两份独立留出脚本上通过原资源重建长度/Adler32 检查；type-0/type-2 不在此结论内。

完整素材、运行报告和 profile 保存在维护者本地，未随公开包分发；本节是历史验收摘要，外部用户需用自己的合法输入重验。
